## Quick start

```bash
tinkerise web t3 my-t3-app --tailwind --no-install
```

```bash
tinkerise web t3 my-t3-app --no-git
```

## When to use

Use `t3` when you want:

- A TypeScript-first full-stack starter
- Opinionated defaults for modern app tooling
- A strong baseline for web products that move fast

## Prerequisites

- Node.js `>=18.17.0`
- `npx` available in your Node install

## Unified flags

| tinkerise flag | Native create-t3-app flag | Notes |
| --- | --- | --- |
| `--typescript` | _(none)_ | T3 is TypeScript-first by default |
| `--tailwind` | `--tailwind` | Enables Tailwind in scaffold setup |
| `--eslint` | `--eslint` | Enables ESLint in scaffold |
| `--biome` | `--biome` | Use Biome linter/formatter |
| `--no-git` | `--noGit` | CamelCase native flag |
| `--no-install` | `--noInstall` | CamelCase native flag |
| `--import-alias <alias>` | `--import-alias` | Import alias (e.g. `@/*`, `~/`) |
| `--app-router` | `--appRouter` | Use App Router |

## Framework-specific behavior

- tinkerise delegates to `create-t3-app`.
- `--CI` is auto-injected when flags are present so all scaffolding runs non-interactively.
- T3 uses camelCase native flags for no-git/no-install/appRouter.
- Pass-through args are enabled.

Native pass-through example:

```bash
tinkerise web t3 my-t3-app -- --drizzle
```

## Generated output

You get the official T3 scaffold output, including:

- TypeScript-first app structure
- T3 defaults for project tooling and scripts
- Optional Tailwind setup when enabled with `--tailwind`
