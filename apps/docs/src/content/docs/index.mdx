## Install command

```bash title="Install tinkerise"
npm install -g tinkerise
```

After install, run the interactive flow with:

```bash title="Start scaffolding"
tinkerise
```

Then use these deeper sections:

- Framework-specific setup: [Scaffolder Guides](/tinkerise/guides/scaffolders/)
