**Create `packages/core/src/enhancements/modules/husky.ts`:**

Uses `defineEnhancement()` from `../define.js`.

Module definition:
```
id: 'husky'
name: 'Husky + lint-staged'
description: 'Pre-commit hooks for linting and formatting staged files'
dependsOn: []
```

Note: `dependsOn: []` -- husky doesn't depend on eslint/prettier in the topological sort. It adapts at runtime by reading the fresh package.json to see what's installed.

**detect(ctx: ProjectContext) -> DetectionResult:**
- Check for `.husky` directory existence (use `access` on `join(ctx.rootDir, '.husky')`).
- Check `ctx.installedDeps` for `'husky'` key.
- Check `ctx.packageJson.scripts` for `"prepare"` script containing `"husky"`.
- `installed: huskyDirExists || 'husky' in ctx.installedDeps`
- `configFiles`: if `.husky` dir exists, add its path.

**install(ctx: ProjectContext) -> InstallResult:**

Step 0 -- Check for `.git` directory: use `access()` on `join(ctx.rootDir, '.git')`. If not found, return `{ success: false, filesModified: [], packagesAdded: [], warnings: ['No .git directory found. Initialize git first: git init'] }`. Per research pitfall 4.

Step 1 -- Install packages: `['husky', 'lint-staged']` versioned from `dependencyVersionMap`.

Step 2 -- Add `"prepare": "husky"` script via `addScript()`.

Step 3 -- Create `.husky` directory: `mkdir(join(ctx.rootDir, '.husky'), { recursive: true })`.

Step 4 -- Write `.husky/pre-commit` hook: content is `npx lint-staged\n`. Write the file.

Step 5 -- Build lint-staged config by reading FRESH package.json from disk (use `readPackageJson()` from `_utils.ts`). Check what tools are currently installed (deps + devDeps merged):

- If `eslint` is in deps: add `'*.{js,jsx,ts,tsx,vue,svelte,astro}': ['eslint --fix']`
- If `prettier` is in deps: add `'*.{js,jsx,ts,tsx,vue,svelte,astro,json,md,css,html}': ['prettier --write']`
- Per locked decision: NO typecheck in pre-commit (that's for CI).

If both are present, combine into a single glob with both commands in array (lint-staged runs them sequentially on the same files). Use separate glob patterns: ESLint targets code files, Prettier targets code + data files.

Step 6 -- Write lint-staged config to package.json: read fresh package.json, add `"lint-staged"` field, write back. Do NOT use `addScript()` for this -- directly modify and write package.json.

Step 7 -- Return InstallResult. `filesModified` includes `.husky/pre-commit` path and `package.json` path. `packagesAdded` includes husky + lint-staged. `success: true`, `warnings: []`.
