**2. Create `packages/core/src/enhancements/modules/_utils.ts`:**

Shared helpers used by all enhancement modules. Three functions:

- `installPackages(packages: string[], opts: { cwd: string; packageManager: PackageManager; verbose?: boolean }): Promise<string[]>` -- uses `execa` to run the correct devDep install command per PM. Command map:
  - npm: `npm install --save-dev ...packages`
  - pnpm: `pnpm add --save-dev ...packages`
  - yarn: `yarn add --dev ...packages`
  - bun: `bun add --dev ...packages`
  - Uses `stdio: 'pipe'` by default (suppress output), `stdio: 'inherit'` when `verbose: true`.
  - Returns the package list passed in.
  - If packages array is empty, return early with `[]`.

- `writeConfigFile(rootDir: string, filename: string, content: string): Promise<string>` -- writes a file to the project root using `fs/promises writeFile`. Returns the absolute path of the written file.

- `addScript(rootDir: string, name: string, command: string): Promise<boolean>` -- reads package.json FRESH each call (not cached), adds the script if not already present, writes back with `JSON.stringify(pkg, null, 2) + '\n'`. Returns `true` if added, `false` if already exists.

Import `PackageManager` type from `../../pm/detect.js`. Import `execa` from `'execa'`. Import `readFile`, `writeFile`, `mkdir` from `'node:fs/promises'`. Import `join` from `'node:path'`.

Also export a `readPackageJson(rootDir: string): Promise<Record<string, unknown>>` helper that reads and parses package.json fresh from disk. This helps modules check current state after prior modules may have modified it.

**detect(ctx: ProjectContext) -> DetectionResult:**
- Check these files in `ctx.rootDir` for existence (use `access` from `fs/promises`):
  - `eslint.config.js`, `eslint.config.mjs`, `eslint.config.cjs`, `eslint.config.ts`
  - `.eslintrc.js`, `.eslintrc.cjs`, `.eslintrc.json`, `.eslintrc.yml`, `.eslintrc.yaml`
- Also check `ctx.packageJson` for `"eslintConfig"` field.
- Collect all found files into `configFiles`.
- `installed: configFiles.length > 0 || !!ctx.packageJson['eslintConfig']`
- `partial: false` (ESLint is binary: configured or not)

**install(ctx: ProjectContext) -> InstallResult:**

Step 1 -- Determine packages to install based on framework:

Define a `FRAMEWORK_ESLINT_MAP` mapping framework IDs to `{ packages: string[], configImports: string[], configSpread: string[] }`:

| Framework | Packages | Config imports | Config spreads |
|-----------|----------|---------------|----------------|
| `next`, `react`, `remix` | `eslint-plugin-react` | `import react from 'eslint-plugin-react'` | `react.configs.flat.recommended`, `react.configs.flat['jsx-runtime']` |
| `vue`, `nuxt` | `eslint-plugin-vue` | `import pluginVue from 'eslint-plugin-vue'` | `...pluginVue.configs['flat/recommended']` |
| `svelte` | `eslint-plugin-svelte` | `import svelte from 'eslint-plugin-svelte'` | `...svelte.configs.recommended` |
| `astro` | `eslint-plugin-astro` | `import astro from 'eslint-plugin-astro'` | `...astro.configs.recommended` |

Step 2 -- Build base packages list: `['eslint', '@eslint/js', 'globals']`. If TypeScript detected (check `ctx.installedDeps` for `'typescript'` key), add `'typescript-eslint'`. If framework has a mapping, add its packages. Version each package from `dependencyVersionMap`, format as `pkg@version`.

Step 3 -- Install packages via `installPackages()`.

Step 4 -- Generate `eslint.config` content:

Build the config file as a string template. Structure:
```js
import { defineConfig } from 'eslint/config'
import js from '@eslint/js'
// conditional: import tseslint from 'typescript-eslint'
// conditional: framework plugin import
import globals from 'globals'

export default defineConfig([
  js.configs.recommended,
  // conditional: ...tseslint.configs.recommended,
  // conditional: framework config spreads,
  // conditional: Vue SFC parser config block (for vue/nuxt with TS)
  {
    languageOptions: {
      globals: {
        ...globals.browser,
        ...globals.node,
      },
    },
    // conditional: settings.react.version: 'detect' for React frameworks
  },
])
```

For Vue/Nuxt with TypeScript, add a `files: ['**/*.vue']` block with `languageOptions.parserOptions.parser: tseslint.parser` (per research pitfall on Vue SFC).

For React frameworks (next, react, remix), add `settings: { react: { version: 'detect' } }`.

Step 5 -- Determine filename: if `ctx.packageJson.type === 'module'`, use `eslint.config.js`. Otherwise use `eslint.config.mjs`. (Per research pitfall 2.)

Step 6 -- Write config file via `writeConfigFile()`.

Step 7 -- Add `"lint": "eslint ."` script via `addScript()`.

Step 8 -- Return InstallResult with `success: true`, `filesModified` containing the config file path, `packagesAdded` containing all installed packages, `warnings: []`.
