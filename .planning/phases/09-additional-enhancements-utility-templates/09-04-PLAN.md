**types.ts** — Shared template options interface:
```typescript
export interface TemplateOptions {
  packageManager?: string  // 'npm' | 'pnpm' | 'yarn' | 'bun'
  noInstall?: boolean
}
```

**shared.ts** — Shared helpers (reusable by MCP, CLI, and lib generators):
- `writeProjectFile(projectDir: string, filename: string, content: string): Promise<string>` — wraps mkdir + writeFile (same pattern as writeConfigFile from _utils.ts but for template projects)
- `runInstall(projectDir: string, pm: string): Promise<void>` — runs `npm install` / `pnpm install` / `yarn install` / `bun install` using execa
- `printTemplateSummary(name: string, projectDir: string, pm: string, templateType: string): void` — prints a styled summary card after generation (project name, path, next steps)

Use `execa` for install command. Use `node:fs/promises` for file operations.

**mcp.ts** — MCP server template generator:

```typescript
export async function generateMcpServer(name: string, options: TemplateOptions): Promise<void>
```

Steps:
1. Resolve package manager: `options.packageManager ?? 'npm'`
2. Create project directory: `mkdir(name, { recursive: true })`
3. Generate `package.json` using JSON.stringify (not string concatenation, per anti-pattern):
   ```json
   {
     "name": "<name>",
     "version": "0.0.1",
     "type": "module",
     "bin": { "<name>": "dist/index.js" },
     "scripts": {
       "build": "tsup",
       "dev": "tsup --watch",
       "start": "node dist/index.js"
     },
     "dependencies": {
       "@modelcontextprotocol/sdk": "^1.26.0",
       "zod": "^3.24.0"
     },
     "devDependencies": {
       "tsup": "^8.4.0",
       "typescript": "^5.7.0",
       "@types/node": "^22.0.0"
     }
   }
   ```
   Note: MCP SDK uses Zod 3 (not 4) — match the dependency.

4. Generate `tsconfig.json`:
   ```json
   {
     "compilerOptions": {
       "target": "ES2022",
       "module": "Node16",
       "moduleResolution": "Node16",
       "outDir": "dist",
       "strict": true,
       "esModuleInterop": true,
       "skipLibCheck": true,
       "declaration": true
     },
     "include": ["src"]
   }
   ```

5. Generate `tsup.config.ts`:
   ```typescript
   import { defineConfig } from "tsup";

   export default defineConfig({
     entry: ["src/index.ts"],
     format: ["esm"],
     dts: true,
     clean: true,
     shims: true,
   });
   ```
   ESM only for MCP server (per SDK requirements).

6. Generate `src/index.ts` — the MCP server entry (per research code example):
   ```typescript
   #!/usr/bin/env node
   import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
   import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
   import { z } from "zod";

   const server = new McpServer({
     name: "<name>",
     version: "1.0.0",
   });

   // Example tool — replace with your own
   server.tool(
     "hello",
     "Say hello to someone",
     { name: z.string().describe("Name to greet") },
     async ({ name }) => ({
       content: [{ type: "text", text: `Hello, ${name}!` }],
     }),
   );

   const transport = new StdioServerTransport();
   await server.connect(transport);
   ```
   Per pitfall #4: use v1 import paths (`@modelcontextprotocol/sdk/server/mcp.js`).

7. Generate `README.md`:
   Brief README with: project name, description, build/run instructions, how to add more tools, how to test with MCP Inspector. Adapt `<name>` throughout.

8. If `!options.noInstall`: run install using `runInstall()`
9. Print summary card using `printTemplateSummary()`

**mcp.ts** — CLI command module:
```typescript
import type { Command } from 'commander'
import { generateMcpServer } from '@tinkerise/core'

export function registerMcpCommand(program: Command): void {
  program
    .command('mcp')
    .summary('Scaffold an MCP server')
    .description('Scaffold a new MCP server project with TypeScript and stdio transport.')
    .argument('<name>', 'Project name')
    .option('--package-manager <pm>', 'Package manager (npm, pnpm, yarn, bun)')
    .option('--no-install', 'Skip dependency installation')
    .action(async (name: string, options) => {
      await generateMcpServer(name, {
        packageManager: options.packageManager,
        noInstall: options.install === false,  // Commander inverts --no-install
      })
    })
}
```
Per locked decisions: top-level command, name + generate flow, no interactive prompts.
