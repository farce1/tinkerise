  <name>Task 1: Wire resolveConfig and --preset/--verbose into scaffold command</name>
  <files>
    packages/cli/src/commands/scaffold.ts

  </files>
  <action>
    **In packages/cli/src/index.ts:**
    1. Add two new global options after the existing options block:
       - `.option('--preset <name>', 'Apply a saved preset')`
       - `.option('--verbose', 'Show detailed output')`
    2. Add `preset` and `verbose` to the ScaffoldOptions-like object flow (they're already passed via Commander's options object).
    3. Update the help examples to include a `--preset` example: `$ {programName} web next my-app --preset my-stack`

    **In packages/cli/src/commands/scaffold.ts:**
    1. Add `preset?: string` and `verbose?: boolean` to the `ScaffoldOptions` interface.
    2. Add imports: `import { resolveConfig, loadPreset } from '@tinkerise/core'` and `import type { TinkeriseUserConfig, PresetData } from '@tinkerise/shared'`.
    3. Modify `resolvePackageManager()` signature to accept `config?: Partial<TinkeriseUserConfig>` and `verbose?: boolean` as additional parameters.
    4. In `resolvePackageManager()`, AFTER the existing `detectPackageManager` call and AFTER the `binary-missing` check:
       - When `pmResult.source === 'default'` AND `config?.packageManager` exists: return `config.packageManager` with an informational message `p.log.info(pc.dim(\`Using ${config.packageManager} (from config)\`))`. Do NOT prompt -- just use the config value.
       - When `pmResult.source === 'default'` AND no config PM: prompt as before.
       - When the CLI flag is provided AND config PM exists AND they differ AND verbose is true: show `p.log.info(pc.dim(\`Overriding config (${config.packageManager} -> ${flagValue})\`))`.
       - The `source === 'lockfile'` case: never show config override messages (lockfile wins silently).
    5. Create a helper function `resolveConfigAndPreset(options: ScaffoldOptions)` that:
       - Calls `resolveConfig({ projectDir: process.cwd(), presetName: options.preset })`
       - If `options.preset`, also calls `loadPreset(options.preset)` to get full `PresetData` (for scaffold-specific fields like framework, flags, category)
       - Returns `{ config, preset }` tuple.
    6. In `buildUserFlags()`, add `config?: Partial<TinkeriseUserConfig>` parameter. If `config?.typescript === true` and `cliOptions.typescript` is not explicitly set, add `typescript: true` to flags. Config typescript is a pre-selection layer, not an override.
    7. In `runInteractiveFlow()`:
       - Call `resolveConfigAndPreset(options)` at the start.
       - Pass preset's `scaffold.framework` to `runPromptFlow({ framework: preset?.scaffold?.framework })` so the framework prompt is skipped when preset defines it.
       - Pass preset's `scaffold.flags` keys as additional preselected options.
       - Pass `config` to `resolvePackageManager()` and `buildUserFlags()`.
    8. In `runCategoryFlow()`:
       - Same config/preset resolution as interactive flow.
       - If preset defines a framework AND the preset's category matches the user-provided category, pre-fill framework. If categories don't match, ignore preset framework (per Pitfall 2 from research).
       - Pass `config` to `resolvePackageManager()` and `buildUserFlags()`.
    9. In `runDirectExecution()`:
       - Resolve config/preset.
       - Pass `config` to `resolvePackageManager()` and `buildUserFlags()`.
       - Merge preset's `scaffold.flags` into preselected options (CLI flags still win per existing mergePromptAndFlags).
    10. Override chain correctness: CLI flags > preset > project config > global config. This is achieved because:
        - resolveConfig already merges as preset(lowest) > global > project > CLI(highest)
        - Preset scaffold flags are treated as preselected defaults (mergePromptAndFlags gives CLI flags priority)
        - Config PM only applies when source === 'default' (no lockfile, no flag)

    **CRITICAL constraints (locked decisions):**
    - Lockfile ALWAYS overrides config for packageManager. Never pass config.packageManager as flagValue to detectPackageManager.
    - Config values apply silently with informational message, not via prompts.
    - CLI flag override of config only shows in --verbose mode.
    - No warning when CLI overrides preset.
  </action>

    - Preset scaffold.flags merge into preselected options
