    **In packages/cli/src/context/session.ts:**
    1. Add imports: `import { readFile, writeFile } from 'node:fs/promises'`, `import { join } from 'node:path'`, `import { existsSync } from 'node:fs'`.
    2. Add constants:
       ```
       const SESSION_FILENAME = '.tinkerise-session.json'
       const SESSION_EXPIRY_MS = 5 * 60 * 1000  // 5 minutes
       ```
    3. Add a Zod schema (import `z` from 'zod') for the session file:
       ```
       const SessionFileSchema = z.object({
         version: z.literal(1),
         framework: z.string(),
         packageManager: z.string(),
         projectDir: z.string(),
         createdAt: z.number(),
       })
       ```
    4. Add `writeSessionFile(projectDir: string, data: { framework: string; packageManager: string })` function:
       - Constructs `SessionFileData` with version: 1, the data fields, projectDir (absolute path), and createdAt: Date.now().
       - Writes JSON to `join(projectDir, SESSION_FILENAME)`.
       - Calls `addToGitignore(projectDir, SESSION_FILENAME)` to auto-add to .gitignore.
       - Wraps in try/catch -- silently fails (session is best-effort).
    5. Add `readSessionFile(dir: string)` function:
       - Reads `join(dir, SESSION_FILENAME)`.
       - Parses JSON and validates with `SessionFileSchema.safeParse()`.
       - Checks expiry: if `Date.now() - data.createdAt > SESSION_EXPIRY_MS`, return empty `{}`.
       - Checks validity: if `package.json` exists at `data.projectDir` (light validation).
       - Returns `SessionContext` with framework, packageManager, projectDir from the file.
       - On any error, returns empty `{}`.
    6. Add `addToGitignore(rootDir: string, entry: string)` -- copy the pattern from `packages/core/src/enhancements/modules/env.ts` lines 142-165. This is a local helper (not imported from core to avoid circular dependency).
    7. Modify `getSessionContext()`:
       - FIRST check in-memory singleton (existing behavior). If it has at least one field set, return it (in-memory takes priority per Pitfall 4 from research).
       - ONLY if in-memory is empty, call `readSessionFile(process.cwd())` and return the file-based result.
       - Make `getSessionContext()` async (it was sync before). This requires updating the call site in add.ts.
    8. Export: `writeSessionFile`, `readSessionFile`, `SESSION_FILENAME` (for tests).

    **In packages/cli/src/commands/scaffold.ts:**

       - Determine the absolute project path: `join(process.cwd(), name)` (the scaffolded project directory).
       - Call `setSessionContext({ framework, packageManager: pm, projectDir: absProjectPath })` (in-memory for same-process flow).
       - Call `await writeSessionFile(absProjectPath, { framework, packageManager: pm })` (file-based for cross-process flow).
    3. Import `join` from 'node:path' if not already imported.

    6. **getSessionContext falls back to file when in-memory empty**: clearSessionContext, write file, verify getSessionContext returns file data.
    7. **writeSessionFile adds to .gitignore**: Write session, read .gitignore, verify `.tinkerise-session.json` entry.
