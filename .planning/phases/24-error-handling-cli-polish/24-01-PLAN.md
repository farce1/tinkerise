<objective>
Create the TinkeriseError base class hierarchy and fuzzy match utility in @tinkerise/core.

Purpose: Establish the structured error foundation that all CLI error paths will use. Every tinkerise error will carry a machine-readable code, a human-readable message, an optional suggestion, and an exit code. This replaces the current pattern where 5 error classes each extend Error directly with no shared metadata.

Output: `packages/core/src/errors/` module with base class, all concrete subclasses, fuzzy match utility, and barrel exports. Existing error definitions removed from their original files and replaced with re-exports.
</objective>

Create `packages/core/src/errors/base.ts` with the TinkeriseError base class and ALL concrete subclasses:

**Base class `TinkeriseError extends Error`:**
- Constructor accepts `{ message, code, suggestion?, exitCode?, cause? }`
- Properties: `readonly code: string`, `readonly suggestion?: string`, `readonly exitCode: number` (default 1)
- Sets `this.name = 'TinkeriseError'`
- Passes `{ cause }` to `super()`

**Refactored existing classes (same constructor signatures as current, but extend TinkeriseError):**

1. `ScaffolderNotFoundError(name: string)` — code: `'SCAFFOLDER_NOT_FOUND'`, suggestion: `"Run 'tinkerise list' to see available scaffolders."`
2. `ScaffolderExitError(scaffolderName: string, scaffolderExitCode: number)` — code: `'SCAFFOLDER_EXIT'`, suggestion: `"Check the output above for details. Run with --verbose for the full error."`, exitCode: scaffolderExitCode. Keep `readonly scaffolderName` and `readonly exitCode` (which is the scaffolder's exit code, mapped to TinkeriseError's exitCode).
3. `FlagNotApplicableError(flag: string, scaffolderName: string)` — code: `'FLAG_NOT_APPLICABLE'`, suggestion: `"Run 'tinkerise web ${scaffolderName} --help' to see supported flags."`. Keep `readonly flag` and `readonly scaffolderName`.
4. `PrerequisiteError(results: PrereqResult[])` — code: `'PREREQUISITE_MISSING'`, suggestion: `'Install the missing tools above, then try again.'`. Keep `readonly results`. Import `PrereqResult` type from `'../prerequisites/checker.js'`.
5. `CyclicDependencyError(cycle: string[])` — code: `'CYCLIC_DEPENDENCY'`, suggestion: `'This is an internal error. Please report it at https://github.com/farce1/tinkerise/issues'`. Keep `readonly cycle`.

**New classes for ad-hoc error paths (Plan 02 will use these when converting process.exit sites):**

6. `InvalidCategoryError(category: string, suggestion?: string)` — code: `'INVALID_CATEGORY'`, message includes valid categories (web, backend, mobile), suggestion: either `"Did you mean '${suggestion}'?"` if provided, else `"Valid categories: web, backend, mobile"`.
7. `InvalidConfigKeyError(key: string)` — code: `'INVALID_CONFIG_KEY'`, suggestion: `"Valid keys: packageManager, typescript, defaultCategory"`.
8. `ConfigValidationError(key: string, value: string, validValues: string)` — code: `'CONFIG_VALIDATION'`, message: `"Invalid value '${value}' for ${key}."`, suggestion: `"Valid values: ${validValues}"`.
9. `UnknownEnhancementError(name: string, availableIds: string[])` — code: `'UNKNOWN_ENHANCEMENT'`, suggestion: `"Available: ${availableIds.join(', ')}"`.
10. `PresetNotFoundError(name: string)` — code: `'PRESET_NOT_FOUND'`, suggestion: `"Run 'tinkerise preset list' to see available presets."`.
11. `CIRequiredArgsError(missing: string[], ciName: string)` — code: `'CI_REQUIRED_ARGS'`, message: `"Running in CI environment (${ciName}). Missing required arguments: ${missing.join(', ')}"`, suggestion: `"Provide all arguments for non-interactive execution: tinkerise <category> <framework> <name> [options]"`.

Each subclass sets `this.name` to its class name.

Create `packages/core/src/errors/fuzzy-match.ts` with:

1. `levenshteinDistance(a: string, b: string): number` — standard dynamic programming implementation (~20 lines). Case-insensitive comparison inside.
2. `findClosestMatch(input: string, candidates: string[], maxDistance = 3): string | undefined` — iterates candidates, returns the one with lowest Levenshtein distance below maxDistance, or undefined if none close enough.

Both functions exported.
