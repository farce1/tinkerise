<objective>
Add contextual usage examples to every subcommand's --help output using Commander's addHelpText('after', ...) API.

Purpose: Users discovering tinkerise see concrete examples of how to use each command, not just option descriptions. This is especially important for compound commands like `config set` and `preset save` where the syntax isn't self-evident from the option list alone. The root program already has examples (added in Phase 4); this plan extends examples to all subcommands.

Output: Every tinkerise subcommand (list, add, doctor, config list/get/set/init, preset save/use/list/delete, mcp, cli, lib, update, monorepo) has 1-3 usage examples shown after `--help` output.
</objective>
