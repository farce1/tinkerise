## Tech Debt

### Phase 5: Enhancement Module System
- **ENH-06 diff quality:** `executor.ts` sets `proposedContent = existingContent` in both ternary branches, producing an always-empty diff. The skip/merge/replace choice still functions — only the preview diff is uninformative. Low impact.

### Phase 8: Configuration & Presets
- **PRE-04 partial:** `preset save` hardcodes `enhancements: []` — does not detect or capture currently installed enhancement IDs. The `PresetData.enhancements` type field exists but is never populated.
- **Preset enhancements display-only:** `preset use` does not auto-apply enhancements from `preset.enhancements[]`. The core preset flow (framework, flags, config) works via `--preset` flag, but enhancement auto-application is not wired.
- **`defaultCategory` orphaned:** Config key `defaultCategory` can be stored via `config set` and is included in the merge chain, but `scaffold.ts` never reads it to pre-fill category in interactive mode. Silently ignored at runtime.

### Phase 10: Distribution & Release Automation
- **DIST-03:** Homebrew formula (`homebrew/tinkerise.rb`) is template-complete with placeholder SHA256. Requires `tinkerise/homebrew-tap` repo creation.
- **DIST-04:** Auto-update workflow (`homebrew/update-formula.yml`) is template-complete. Requires `HOMEBREW_TAP_TOKEN` secret and tap repo deployment.

### Phase 9: Additional Enhancements
- **ADD-07:** Changelog generation intentionally descoped per locked user decision. Commitlint provides commit enforcement only.
- **ADD-08:** Example test files intentionally excluded per locked user decision. Testing module generates Vitest config only.

### Phase 4: Web Framework Scaffolders
- **QA-06 scope:** Upstream drift detection snapshots exist for 7 web scaffolders only. Backend and mobile scaffolders have no drift detection — upstream flag changes for those tools will not be automatically detected.

### Miscellaneous
- **Dead export:** `tinkeriseSummary` (non-card variant) exported from `@tinkerise/core` but never imported by CLI. `tinkeriseSummaryCard` is used exclusively.

**Total:** 10 items across 5 phases. Items are: 3 scope gaps (preset enhancements, defaultCategory, drift coverage), 2 external infra dependencies (Homebrew), 2 intentional scope decisions (ADD-07, ADD-08), 1 quality issue (diff display), 1 dead export, 1 CI config gap (E2E tests not enabled in CI by design).
