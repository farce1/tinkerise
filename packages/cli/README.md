# @tinkerise/cli

CLI entry point for [tinkerise](https://www.npmjs.com/package/tinkerise) — commands, prompts, and user-facing output.

This is an internal package. Install the main package instead:

```bash
npm install -g tinkerise
```

See the [tinkerise README](https://www.npmjs.com/package/tinkerise) for full documentation.
